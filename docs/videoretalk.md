# VideoRetalk 视频底片模式

此模式作为新选项加入，不删除或迁移原照片驱动模式、供应商配置、照片和历史运行。

## 录制底片

- 建议竖屏 1080×1920、30fps，MP4（H.264）；关闭美颜和动态滤镜。
- 固定机位、镜头接近眼睛高度、正面均匀光线。从头顶上方拍到腰部，双手动作保留在画面内。
- 自然讲话、适度点头和手势，避免遮嘴、大幅转头、走动或其他人物入镜。
- 无需固定稿子，不必与以后每条文案完全一致。讲一段熟悉的内容即可，情绪和手势尽量通用。
- 建议录制 60 至 90 秒，用于较短的新口播。视频和配音都必须大于 2 秒、小于 120 秒。
- 官方要求视频宽高各为 640 至 2048 像素、15 至 60fps、H.264/H.265、MP4/MOV/AVI、不超过 300MB。

衣服、背景、身体动作来自底片。同一造型可以重复使用；想换衣服、背景、人物或姿势，需新上传对应底片。换形象库照片不会自动换脸或换装。新语音不一定与原手势含义匹配，效果需实测。

## 在工作台中使用

1. 打开“服务设置”，在数字人视频中点“添加”，选择“阿里云百炼（视频口型替换）”。
2. 填入华北2（北京）地域的百炼 API Key。接口地址和 `videoretalk` 模型 ID 自动填写，不需要 Wan 模板的业务空间 ID。原 Wan 设置不要修改。
3. 保存后可“测试连通”：这里只检查 Key 和临时上传接口，不会提交付费任务，也不保证生成权限或账户余额。
4. 到“形象与素材”上传人物视频，或在创作页选择 VideoRetalk 服务后直接上传。文件保存在本机 `assets/source_videos/`，可在后续创作中复用；文件名用作素材名称。
5. 在创作页选择 VideoRetalk 服务、底片、自己的音色和语音服务，填文案。此模式不需要再选场景照片或独立身份参考图。
6. 建议首次只生成约 10 秒的新配音，确认口型和画质后再做长片。

配音阶段仍使用音色库与所选语音服务，底片原声不会代替克隆配音。模型主要替换口型，不是根据文案创造全新肢体动作。

## 时长、费用与失败处理

- 总配音不能短于或等于 2 秒，也不能达到 120 秒，且不超过 30MB。底片必须不短于配音；不支持自动把一段短底片拼成无限长口播。
- 程序按实际配音长度截取底片的前半段，保留正向动作。不会倒放循环，不会静默截断配音，也不会改用照片、本地模型或其他音色。
- 官方文档核对时（2026-10-20）口型替换为 0.08 元/秒，30 秒约 2.40 元，另计语音生成费；以实际账单为准。免费额度及有效期需自行在控制台查看。
- 历史记录可继续查询已提交任务；已完成片段不会重复提交生成。保存了任务 ID 后，查询或下载失败可以续跑。云端结果地址有有效期，任务过期后不能保证继续下载。
- 提交瞬间断网或进程退出、无法确定是否创建了任务时，程序会阻止盲目重提。先在百炼查看任务与账单，确认后再新建运行。
- 仅使用模拟云端接口和本地测试视频验证了协议、失败处理及复用逻辑，不代表已通过账号权限或真人效果实测。

命令行也可使用 `python -m autovid graph run --source-video "D:\素材\上半身.mp4" --script-file "examples\自然口播样片.txt"`；先在配置中选择已保存的 VideoRetalk Provider 和克隆音色。照片模式仍使用 `--scene-photo`。
